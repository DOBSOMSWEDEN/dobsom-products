# W´n´R Winter set II

**Färg:** Wine  
**Pris (RRP):** 999 SEK  
**Storlekar:** 36, 38, 40, 42, 44, 46, 48  
**Kategori:** null  

## Produkttext

Vindset med tunt, funktionellt fleecefoder. Jackan har 2 framfickor med blixtlås samt innerficka med blixtlås. Vindslå bakom frontlåsen. Skön mudd i ärmavsluten och också är justerbara med hjälp av kardborre. Elastisk string med dragsko i nederkant och krage för justering. Skön fleece på insida krage samt i fickor. Byxorna har långa delbara blixtlås i sidorna. 2 blixtlåsförsedda fickor som också har ett skönt fleece på insidan. Elastisk string med dragsko för justering i benavsluten. Reflexer. Hela setet har fluorkarbonfri impregnering för vatten och smutsavvisning.

MATERIAL: 100% Polyester
TVÄTTRÅD: Max 40° C, ej kemtvätt, strykning på låg värme, ingen torktumling, inga blek eller sköljmedel, tvättas med liknande färger, tvättas med stängda dragkedjor.
TILLVERKNINGSLAND: Kina
